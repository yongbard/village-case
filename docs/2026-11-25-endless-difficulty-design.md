# 무한 모드 난이도 올리기 — 짧은 설계

작성: 2026-11-25. 사용자 승인("네") 2026-11-25.

## 왜

사용자 말: "무한모드가 좀 쉽던데요?", "범인이 하나였음, 판의 크기가 3 x 3이라 3명정도면 조사해도 바로 답이 나오는 경우가 많았음". 무한 모드는 "스테이지를 다 해본 사람이 하는 정도로".

지금 상태 (src/core/generate.ts)
- 틀(판 크기·주범·공범·말썽꾼 수·직업 등급)은 몇 번째 사건(n)으로 정해진다. 1 ~ 4번째는 늘 3×3, 주범 1명(1·2번째는 공범도 없음). 시드는 그 틀 안에서 누가 어디 있는지만 정한다.
- generateValid 는 규칙에 맞는 첫 사건을 바로 낸다. 난이도를 보지 않는다(스테이지는 build-stages 가 난이도 점수로 골랐다).

측정 (n 마다 시드 20개, logs/endless-probe/before.txt). 필요한 진술 칸 = 해설 단계가 쓰는 진술의 칸 수.

```
n    판   주범 공범 말썽꾼  난이도 1~5 분포  필요한 진술 칸 중앙값/최소  생성 중앙값/최대
1    3×3  1    0    0      20/0/0/0/0      2 / 1                     1 / 6 ms
3    3×3  1    1    0      12/6/2/0/0      3 / 1                     1 / 4 ms
5    3×4  1    1    1      12/7/1/0/0      3 / 2                     3 / 14 ms
8    3×4  1    2    1       5/8/6/1/0      5 / 1                     7 / 28 ms
10   3×4  2    2    2       5/6/8/0/1      6 / 2                     9 / 24 ms
14   4×4  2    2    2       3/1/2/4/10     6 / 0                     84 / 311 ms
18   4×5  2    2    3       2/4/6/5/3      8 / 3                     119 / 531 ms
22   4×5  3    1    3       1/8/5/1/3      8 / 3                     120 / 1970 ms
30   4×5  3    1    3       6/6/2/0/3      7 / 3                     195 / 2322 ms
```

스테이지 4 ~ 6장은 난이도 2 ~ 5, 필요한 진술 칸이 대부분 7 ~ 15칸이다.

## 목표 / 비목표 / 실패 조건

목표: 스테이지를 다 깬 사람이 1번째 사건부터 생각해야 풀린다. 3명쯤 조사해서 답이 나오는 사건이 나오지 않는다.

비목표: 스테이지 30개, 규칙, 진술 문장, 힌트, 저장 형식, 화면.

실패 조건
- 같은 사건 코드(n-시드)가 기기마다 다른 사건이 된다 (사건 코드로 같은 사건을 다시 하는 기능이 깨짐).
- 사건이 5초 안에 뜨지 않는다 (check-ui 의 "endless: case appears within 5 s").
- 거르기 한도 안에서 기준을 넘는 사건을 못 찾아 쉬운 사건이 자주 나온다.

## 방법 (사용자가 고름: C)

- A. 시작만 올림: 3×3 을 빼고 틀을 빨리 키움. 간단하지만 같은 틀 안에서 운 좋게 쉬운 사건은 그대로 나온다(측정: 4×5 주범 3 에서도 셋 중 하나가 난이도 1).
- B. 쉬운 사건 거르기만: 증상을 직접 겨냥하지만 초반 3×3 틀은 거를 후보 자체가 다 쉽다.
- C. A + B — 고름. 시작을 스테이지 4장 수준으로 올리고, 남은 쉬운 사건을 거른다.

## 설계

틀 (endlessParams, 값은 계획 단계 측정으로 조정 가능)
- 1 ~ 3번째: 4×4, 주범 1, 공범 2, 말썽꾼 2 (스테이지 4장 시작 수준)
- 4 ~ 7번째: 4×4, 주범 2, 공범 2, 말썽꾼 2 (5장 수준)
- 8 ~ 12번째: 4×5, 주범 2, 공범 2, 말썽꾼 2
- 13번째부터: 4×5, 주범 3, 공범 1, 말썽꾼 3 (30스테이지 수준, 상한)
- 직업 등급: 1번째부터 3등급까지, 빨리 전부(5등급)로 넓힌다.
- 판·말썽꾼·주범·악 수는 n 에 대해 줄지 않는다(지금 규칙 유지).

거르기
- 같은 시드에서 후보 사건을 차례로 만들고, 난이도 3 이상이면서 필요한 진술 칸이 5칸쯤 넘는 첫 사건을 낸다.
- 정해진 수만큼 만들어도 없으면 그중 가장 어려운 것을 낸다.
- 선택은 기기 속도와 상관없어야 한다: 시간 한도가 아니라 정해진 일의 양(후보 수, 해설 계산의 한도)으로 거른다.

지킬 것
- 사건은 지금처럼 5초 안에 뜬다. 다음 사건은 플레이 중에 미리 만들어 둔다(지금 있는 prefetch).
- 예전 무한 모드 사건 코드와 이어 하던 판은 다른 사건이 된다. 최고 기록은 그대로.

## 빌더에게 맡기는 것

- 정확한 기준값(난이도, 진술 칸 수), 후보 수, 등급을 넓히는 속도. 측정해서 대부분의 시드가 기준을 넘고 생성 시간이 5초 안에 들게 정한다.
- 해설 계산을 시간 대신 일의 양으로 끊는 방법.
- 기존 시험·check-ui 의 무한 모드 확인(시드 사건 판 크기 등)을 새 틀에 맞게 옮기는 방법.
